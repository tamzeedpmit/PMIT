#  Medicine Reminder Application

A mobile application that helps patients take the right medicine at the right time.  
It reduces missed doses and medication errors while offering features such as emergency SOS, nearby hospitals, and pharmacy locations.

---

##  Features
- Medicine schedule and reminders  
- Emergency SOS alert  
- Nearby hospital and pharmacy finder  
- User-friendly interface  
- Secure data storage

---

## 🛠️ Technologies Used
- **Java** for application logic  
- **XML** for UI design  
- **Firebase** for authentication and data storage  
- **Google Maps API** for location services
